# 学习进度云同步部署指引（Cloudflare Workers + KV）

把学习进度备份到云端，**换设备、清缓存、多台设备登录都不丢数据**。只需要照下面做一次，约 10 分钟。

---

## 第一步：创建 KV 存储空间（5 分钟）

1. 打开 https://dash.cloudflare.com/ 用你的账号登录
2. 左侧菜单找到 **Workers 和 Pages** → 点击进入
3. 在顶部页签找 **KV**（或左侧次级菜单 **KV**）→ 点 **创建命名空间**
4. 名称随意，比如填：`sync_studyc`
5. 点 **添加** 创建完成

> 这一步做好后记住这个命名空间叫什么（教程里用 `sync_studyc`）。

## 第二步：创建并部署 Worker（5 分钟）

1. 还在 **Workers 和 Pages** 页面，点右上角 **创建应用程序**（Create an application）
2. 选 **Workers** → **创建 Worker**（Create Worker，不是"Worker 路由"）
3. 名称填：`studyc-sync`（或随意）
4. 出现代码编辑器后，**先清空里面默认的代码**（全选删除）
5. 把 `cloudflare-worker/worker.js` 文件的内容**全部复制粘贴进去**
6. 点右下角/右上角 **部署**（Deploy），等一两秒提示部署成功
7. 点 **继续处理项目**（Continue to project）进入详情页
8. 在详情页顶部会有一个网址，长这样：`https://studyc-sync.你的账户名.workers.dev`
   —— 复制保存这个网址，**这是前端要填的"云端服务器地址"**

## 第三步：把 KV 绑定到 Worker（2 分钟）

1. 在 Worker 详情页点 **设置**（Settings）→ 左边找 **变量**（Variables）
2. 往下找到 **KV 命名空间绑定**（KV namespace bindings）→ 点 **编辑** 或 **添加绑定**
3. **变量名称**填：`SYNC_KV`（必须一字不差）
4. **KV 命名空间**：选择刚才创建的 `sync_studyc`
5. 点 **保存**（Save）

## 第四步：网页上开启云端同步（2 分钟）

部署完成后，回到学习网站 https://wwwgood.github.io/studyc/ ：

1. 顶部点 **☁️ 同步** 按钮（顶栏右侧）
2. 在弹窗里找到 **☁️ 云端同步** 区域
3. 填入三样东西：
   - **云端地址**：第二步保存的 `https://studyc-sync.xxx.workers.dev`
   - **云端账号**：随意，建议填孩子的名字拼音，比如 `ziyu`
   - **云端密码**：自己设一个密码（记好，别告诉孩子会乱改）
4. 点 **保存配置**，然后点 **上传到云端** 备份一次
5. 以后每次学习，页面会自动备份到云端（几秒内）

## 换新设备 / 数据丢失后怎么找回？

- 新设备打开网页 → 点 **☁️ 同步** → 填**同样的账号和密码**
- 点 **从云端恢复** → 所有进度、金币、打卡全部回来

## FAQ

**Q：这个要花钱吗？**
A：不需要。Cloudflare 免费版：Worker 每天 10 万次请求、KV 每天 10 万次读 / 1000 次写入，孩子一天做几百题都远远用不完，完全免费。

**Q：数据安全吗？**
A：你的账号密码只有你自己知道（存在你自己的浏览器里，发给云端时也是加密传输 https）。云端只认"账号+密码"匹配的访问。密码只有你知道，孩子瞎猜也进不来。

**Q：会覆盖坏我的数据吗？**
A：页面采用"自动备份 + 手动恢复"：平时只把本地进度上传到云端，不会自动拿云端覆盖本地。只有你主动点「从云端恢复」才会用云端覆盖本地，两边的数据都可以导出来再导进去，很安全。

**Q：地址是 http 还是 https？**
A：官方给的地址自动就是 https，直接复制即可。
