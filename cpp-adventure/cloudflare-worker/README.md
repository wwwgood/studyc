# 学习进度云同步部署指引

把学习进度备份到云端，**换设备、清缓存、多台设备登录都不丢数据**。照下面做一次，约 10 分钟。

> 本指引同时适用于 **Cloudflare 新版控制台**（左侧菜单有"构建 / 存储和数据库 / Workers KV"）与 **Pages 项目**（`xxxx.pages.dev`）方式。

---

## 第一步：创建 KV 存储空间 ✅（多半已完成）

1. 登录 https://dash.cloudflare.com/
2. 左侧 **构建** → **存储和数据库** → **Workers KV**
3. 点 **创建命名空间**，名称填：`sync_studyc` → **添加**

> 已经建好的，跳过这步。创建时页面弹出的"API 令牌 / 命名空间 ID"之类**全部不用保存**。

---

## 第二步（二选一）：部署后端接口

### 方式 A：用 Worker（推荐，代码在网页里直接粘贴）

1. 左侧 **构建** → **计算** → 找到"创建应用程序 / 创建 Worker"
2. 名称填 `studyc-sync`，进入代码编辑器后**清空默认代码**
3. 打开本机文件 `cpp-adventure/cloudflare-worker/worker.js`，全部复制粘贴进去
4. 点 **部署** → **继续处理项目**
5. 记下页面顶部网址：`https://studyc-sync.你的账户.workers.dev`

### 方式 B：你已经建好了 Pages 项目（`studyc.pages.dev`）时用这个

不要删除重来，Pages 也能跑这个接口：

1. 在电脑上准备好一个文件夹 `cloud-upload`（里面只有一个文件 `_worker.js`，助手已生成）
2. 回到你 Pages 项目 `studyc` 的管理页面，点 **创建部署**（Create deployment）
3. 选 **直接上传**（Direct upload），把整个 `cloud-upload` 文件夹拖进上传区
4. 点 **保存并部署**（Save and Deploy）
5. 部署成功后，云端地址就是：`https://studyc.pages.dev`

---

## 第三步：绑定 KV 命名空间（两种方式都在"变量/绑定"里）

- **Worker 方式**：你的 Worker 详情页 → **设置** → **变量** → **KV 命名空间绑定** → **添加绑定**
- **Pages 方式**：你的 Pages 项目 → **设置** → **绑定**（Bindings）→ **KV 命名空间绑定** → **添加绑定**

绑定内容：
- **变量名称**：`SYNC_KV`（必须一字不差）
- **KV 命名空间**：`sync_studyc`
- 点 **保存**

---

## 第四步：网页上开启云端同步

打开学习网站 https://wwwgood.github.io/studyc/：

1. 顶部点 **☁️ 同步** 按钮
2. 找到 **☁️ 云端同步** 区块
3. 填三样：
   - **云端地址**：`https://studyc-sync.xxx.workers.dev`（方式A）或 `https://studyc.pages.dev`（方式B）
   - **云端账号**：如 `ziyu`
   - **云端密码**：自己设
4. 点 **保存云端配置** → 点 **上传到云端** 备份一次
5. 以后每次学习自动备份；换设备/清缓存时用同一账号密码点 **从云端恢复**

---

## 常见问题

**要花钱吗？** 不用。免费版：Worker/Pages 每天 10 万次请求，KV 每天 10 万次读 / 1000 次写，完全够用。

**上传部署后怎么知道成功？** 浏览器打开 `云端地址/api/ping`，看到 `{"ok":true,"name":"studyc-sync"}` 就成功了。

**会覆盖坏数据吗？** 页面平时只上传不覆盖，只有你主动点「从云端恢复」才用云端覆盖本地。双保险：本地一份 + 云端一份 + 手动导出文件一份。
